🚀 TO RUN IN VS CODE (5 STEPS):

1️⃣  OPEN PROJECT
    • File → Open Folder
    • Select: womens_economic_empowerment_vscode

2️⃣  OPEN TERMINAL
    • View → Terminal (or Ctrl+~)

3️⃣  CREATE & ACTIVATE VIRTUAL ENV
    python3 -m venv .venv
    source .venv/bin/activate

    ✓ Should see (.venv) in terminal prompt

4️⃣  INSTALL DEPENDENCIES
    pip install -r requirements.txt

    ✓ Wait 2-5 minutes for completion

5️⃣  RUN THE SERVER
    python ndap_app.py

    ✓ Server starts on http://localhost:5000
    ✓ Open in browser → See dashboard!

❓ TROUBLESHOOTING:

Issue: "port 5000 already in use"
→ Kill process: lsof -i :5000 | grep -v PID | awk '{print $2}' | xargs kill -9

Issue: "Module not found"
→ Check virtual env active: source .venv/bin/activate
→ Reinstall: pip install -r requirements.txt

Issue: "Datasets not found"
→ Check: ls -la data/raw/
→ Should see 16 CSV files (1.csv through 16.csv)

Issue: "Python not found"
→ Use: python instead of python3
